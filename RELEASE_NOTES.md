**Discord Server Builder** is a desktop app for running your Discord bots from one place. Build whole server layouts, moderate members and channels, and let your mods sign in with Discord.

## Download

Pick one, both are the same app by **Pixelplayz2215**:

| File | What it is |
| --- | --- |
| **DiscordServerBuilder-setup.exe** | **Installer.** Adds Start menu and desktop shortcuts and an uninstaller. Recommended. |
| **DiscordServerBuilder-portable.exe** | **Portable.** No install; run it from any folder or a USB stick. |

Bot owners paste their bot token. Moderators click **Sign in with Discord** and paste the portal address their server owner gave them. Both versions tell you when there's an update and install it in one click.

> ⚠️ **The only official download is this GitHub page:** https://github.com/Pixelplayz2215/discord-server-builder/releases/latest
> Copies from anywhere else could be changed to steal your bot token. Never share your token with anyone, including people claiming to be Pixelplayz2215.

Windows may show a SmartScreen warning the first time because the app isn't code-signed. Click **More info → Run anyway**.

## Everything in the app

- **Multiple bots.** Each bot gets its own page with its servers, an online status and an invite link.
- **Server details.** Stats, owner, boosts, roles and the bot's permissions.
- **Members and moderation.** Search members, then warn, time out, kick, ban or unban them, and see each member's case history. You can also change nicknames and roles, prune inactive members, and view the audit log.
- **Raid tools, AutoMod and server logs.** Lock down the server, pause invites, clean up a wave of new joins, manage Discord's AutoMod, and log server events to a channel.
- **Channels.** Send messages as the bot, purge, lock, set slowmode, edit permissions, rename, create and delete.
- **Builder and backups.** Build a server's roles, categories, channels and permissions from templates, clone an existing server, and back up and restore servers.
- **Social alerts.** Post when a YouTube channel uploads or a Twitch channel goes live.
- **Reaction roles.** Members react to a message to give themselves roles, with your server's own emojis or standard ones.
- **Tickets.** Members open a private support channel with one button. Staff claim and close it, and every closed ticket is saved as a transcript, images included.
- **Welcome & goodbye cards.** Greet new members with a card made for them, and say goodbye when someone leaves. Design the background, font, colours and text yourself, for free.
- **Polls.** Members vote by reacting, and each answer gets a bar in its emoji's colour, like Discord's own polls. Post them from the app or with `/poll` in Discord.
- **Settings.** 8 themes (including light ones), custom colours, your own logo and app name, UI scale, text size, corner roundness and fonts. The app can keep running in the tray.
- **Mod sign-in and slash commands.** Moderators sign in with Discord instead of using the bot token, or use `/warn`, `/ban` and the other mod commands in Discord, and only get what their Discord permissions allow. See [docs/MOD-PORTAL.md](https://github.com/Pixelplayz2215/discord-server-builder/blob/main/docs/MOD-PORTAL.md) to set up a portal for your own bot.

Your bots, tokens and settings are stored only on your PC (`%APPDATA%\Discord Server Builder`). Tokens are encrypted with Windows DPAPI.
